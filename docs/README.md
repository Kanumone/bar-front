# Документация проекта "Ветки и корни"

Интерактивная визуальная новелла с элементами путешествия и мини-играми.

## Обзор проекта

Это React + TypeScript + Phaser 3 приложение, представляющее собой визуальную новеллу с интерактивными элементами. Игра рассказывает историю главного героя Алексея, который отправляется в путешествие по России, следуя подсказкам своего деда.

### Основные технологии
- **React 19** - пользовательский интерфейс
- **TypeScript** - типизация
- **Phaser 3** - игровые сцены и физика
- **Zustand** - управление состоянием
- **Vite** - сборка проекта
- **Framer Motion** - анимации

## Быстрый старт

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build

# Запуск тестов
npm test
```

## Ключевые особенности

- **Адаптивная визуальная новелла** с текстом, выборами и анимированными персонажами
- **Плавные сцены перемещения** с параллакс-эффектами
- **Интерактивная карта России** с возможностью навигации
- **Разнообразные мини-игры**: детектив, кулинария, полет, 2048
- **Аналитика действий игрока** и прогресс
- **Интеграция с Telegram Web Apps**

## Файловая структура

```
src/
├── app.tsx                 # Главный компонент приложения
├── main.tsx               # Точка входа
├── core/                  # Ядро приложения
│   ├── state/            # Zustand stores
│   ├── types/            # TypeScript типы
│   ├── hooks/            # React хуки
│   └── constants/        # Константы
├── features/             # Игровые функции
│   ├── slides/          # Система слайдов
│   ├── detective-game/  # Детективная игра
│   ├── cooking-game/    # Кулинарная игра
│   ├── flying-game/     # Игра-полет
│   ├── game-2048/       # Игра 2048
│   ├── game-map/        # Интерактивная карта
│   └── move-phaser-scene/ # Сцены движения
├── ui/                   # UI компоненты
│   ├── components/      # Переиспользуемые компоненты
│   ├── scenes/         # Обертки для сцен
│   └── layout/         # Компоненты макета
├── processes/           # Бизнес-процессы
│   └── game-flow/      # Менеджер игрового потока
├── api/                # API интеграция
├── assets/             # Ресурсы (изображения, звуки)
└── utils/              # Утилиты
```

Этот проект демонстрирует современный подход к созданию интерактивных игр с использованием веб-технологий, сочетая нарративные элементы с геймплейными механиками.
